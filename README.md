Trabajo final de lenguaje de programacion

**IMPORTANTE:** Para instalar esta versión, empieza por [INICIAR_AQUI.md](INICIAR_AQUI.md).
Incluye inicio simplificado con Docker, datos ficticios automáticos y guía manual.

## Inicio rápido con Docker

Requisitos:
- Docker Desktop instalado y funcionando.

Para iniciar:
docker compose up -d --build

Para detener:
docker compose down

Consultar INICIAR_AQUI.md para conocer las cuentas de prueba.
